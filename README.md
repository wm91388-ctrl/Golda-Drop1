# Golda Drop

> Браузерная игра про апгрейд скинов. Крути. Выбивай. Забирай.

**Версия:** 2.0  
**Стек:** Node.js + SQLite (node:sqlite), HTML + CSS + Vanilla JS   
**Демо-режим:** виртуальная валюта, без реальных ставок

---

## 📖 Что это

Golda Drop — симулятор апгрейда скинов, в котором можно:

- покупать скины в магазине;
- открывать кейсы и получать дропы до 200 000 MCOIN;
- крутить колесо апгрейда — рискнуть одним скином ради другого;
- участвовать в кейс-баттлах (2–4 игрока) и кейс-рулетке (до 10 игроков);
- играть в скин-баттл «Больше/Меньше»;
- добавлять друзей и общаться в личных сообщениях;
- собирать косметику профиля (рамки, фоны, титулы);
- оформлять VIP-подписку;
- выводить скины на демо-карту с комиссией 10%.

Вся экономика и логика — на сервере. Клиент только рисует.

## ✨ Возможности

### Игровые режимы
- ⬆️ **Апгрейд** — шанс до 95%, донат к цене предмета, рейтинг удачи
- 📦 **Кейсы** — 4 штуки: Новичок, Профи, Эксперт, Мифический
- ⚔️ **Кейс-баттлы** — победитель забирает все скины
- 🎲 **Скин-баттл** — «больше/меньше», один угадал — забирает оба
- 🎰 **Кейс-рулетка** — банк = ставка × игроков
- 👥 **Друзья** — заявки, личные сообщения

### Редкость (9 уровней)
| Класс | Цена | Визуал |
|---|---|---|
| `.r0` | < 50 | серый |
| `.r1` | < 150 | синий |
| `.r2` | < 400 | фиолетовый |
| `.r3` | < 1000 | розовый |
| `.r4` | < 8000 | красный |
| `.r5` | < 30 000 | золотой |
| `.r6` | < 60 000 | радуга |
| `.r7` | < 100 000 | свечение |
| `.r8` | 100 000+ | космос |

### Прогрессия
- 37+ достижений с наградами
- 3 квеста дня
- 5 уровней удачи (множитель к шансу)
- Уровни аккаунта (XP)
- Топ-10 дропов

### Косметика
- Рамки: золото, радуга, плазма
- Фоны: туманность, аврора, город, золото, матрица
- Титулы: «Снайпер», «Коллекционер», «Легенда»
- VIP-плашки
